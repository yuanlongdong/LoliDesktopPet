# 直播联动协议（TCP JSON-lines）

桌宠（手机端）作为一个 **TCP 客户端**，连到你电脑上跑的 `bridge.py` 端口，
按行接收 JSON 事件（每行一条，UTF-8）。收行 → 解析 → 桌宠做出反应。

- 协议：一行一条 JSON 对象，`\n` 分隔
- 默认端口：**17632**（可在 App 设置页改）
- 连接方向：**手机连电脑**，所以手机和电脑要在同一局域网（或电脑有公网 IP / 内网穿透）
- 断线：App 会自动重连（2s 起步、指数退避，最多 30s），直播中网络抖一下不用管

## 事件字段

```json
{"type":"gift","user":"小可爱","item":"玫瑰","count":3,"amount":30,"text":""}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `type` | string | 是 | 事件类型，见下表 |
| `user` | string | 否 | 触发人昵称 |
| `item` | string | 否 | 礼物名 |
| `count` | int | 否 | 数量 / 连击 |
| `amount` | number | 否 | 抖币数（`gift` 且 `amount>=100` 会自动升格为大额礼物） |
| `text` | string | 否 | 弹幕原文（`comment` 用） |

未知类型会被忽略；缺字段不影响解析（都有默认值）。

## type 取值与对应反应

| type | 含义 | 桌宠反应 |
|---|---|---|
| `gift` | 收到礼物 | 弹一下 + 说「收到礼物」台词 |
| `gift_big` | 大额礼物（≥100 抖币自动升格） | 弹一下 + 播庆祝动画 + 说「大额礼物」台词 |
| `follow` | 有人关注 | 弹一下 + 播庆祝动画 + 说「收到关注」台词 |
| `like` | 收到点赞 | 弹一下 + 说「收到点赞」台词 |
| `comment` | 弹幕 | 命中关键词播庆祝动画，否则弹一下 + 说「弹幕互动」台词 |
| `enter` | 有人进场 | 说「有观众进场」台词 |

每种类型有独立冷却（礼物最勤、点赞/进场最克制），弹幕很密也不会刷屏。

## 跑起来

```bash
# 1) 电脑上起桥（读 stdin，监听所有网卡）
python3 bridge.py --port 17632

# 2) 想先看效果：另开一个终端，把模拟事件 pipe 进去
python3 mock.py | python3 bridge.py --port 17632
# 或者追尾一个文件
python3 bridge.py --port 17632 --file events.txt
```

电脑防火墙要放行 `17632` 端口。查电脑局域网 IP（例如 Windows `ipconfig`，
`192.168.x.x`），填进 App 设置页的「桥地址」，打开「直播联动」即可。

## 通过 DyHub 接入真实直播事件（可选）

本仓库提供了一个标准库适配器 `dyhub_sse_adapter.py`，把兼容 DyHub 的 SSE 事件流转换成桌宠桥需要的 JSON-lines 格式。它**不是采集器**；电脑上必须先运行并连接好数据源。

1. 按 [DyHub 项目说明](https://github.com/ymstar/dyhub) 在电脑上部署并连接目标直播间。
2. 在电脑终端运行以下命令（默认 DyHub SSE 地址为本机 `8757` 端口）：

   ```bash
   cd tools/live-bridge
   python3 dyhub_sse_adapter.py \
     --url 'http://127.0.0.1:8757/api/events?types=chat,gift,member,like,follow' \
     | python3 bridge.py --port 17632
   ```

3. 手机与电脑处于同一可信局域网，在桌宠设置里填电脑的局域网 IP 和端口 `17632`，打开「直播联动」。

适配映射：chat → comment、gift → gift、member → enter、like → like、follow → follow。礼物事件是否能收到，取决于数据源的登录态和平台当前策略。建议先用数据源控制台确认事件确实出现，再检查手机桥接状态。

**网络安全：** `bridge.py` 默认监听所有网卡且不带身份验证，只在可信局域网使用，并通过电脑防火墙限制访问；不要直接把端口暴露到公网。DyHub 是独立第三方项目，需自行审阅其使用方式、许可和平台规则。本仓库不包含其采集器或登录凭据。

## 接真实抖音直播数据

桌宠只负责「收到事件 → 反应」，**不负责去抖音抓数据**。抖音直播数据的获取方式由你选：

- **推荐**：用「抖音直播伴侣 / 第三方直播数据工具」在电脑上拿到礼物、弹幕、关注，
  把它们转成上面的 JSON 行，`pipe` 或写文件喂给 `bridge.py`（写一个小脚本即可）。
- 本项目只承诺协议稳定、App 侧零依赖；接入侧的具体实现取决于你所用的抖音数据源，
  属于第三方行为，与本项目无关。

## 字段 → 台词

台词分类名（可在 App 的「台词库」里改）：
`gift`（收到礼物）`giftBig`（大额礼物）`follow`（收到关注）`like`（收到点赞）
`comment`（弹幕互动）`enter`（有观众进场）。

没有对应台词分类时，桌宠只做动作、不说台词，不会报错。
